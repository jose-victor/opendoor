# Security policy

*Português abaixo.*

## Supported versions
Only the `main` branch and the live site (https://opendoor-fawn.vercel.app) are supported.

## Reporting a vulnerability
Please **do not open a public issue**. Write to **[project e-mail, coming soon]** with:
- what is affected (pipeline, website, API route, published data);
- how to reproduce it;
- the impact you expect.

We will acknowledge your report within 7 days and keep you posted until it is fixed. Once it is fixed, we are happy to credit you, if you want.

Things we care about in particular: leaking the Gemini API key, abuse of `/api/explain`, and text from third-party repositories being treated as instructions by the model (prompt injection).

# Política de segurança

## Versões suportadas
Só a branch `main` e o site no ar (https://opendoor-fawn.vercel.app).

## Como relatar uma vulnerabilidade
Por favor, **não abra uma issue pública**. Escreva para **[e-mail do projeto, em breve]** contando:
- o que é afetado (pipeline, site, rota da API, dados publicados);
- como reproduzir;
- o impacto que você espera.

Respondemos em até 7 dias e mantemos você informado até a correção. Depois de corrigido, damos o crédito a você, se quiser.

O que mais nos preocupa: vazamento da chave da Gemini API, abuso de `/api/explain` e texto de repositórios de terceiros sendo tratado como instrução pelo modelo (prompt injection).
